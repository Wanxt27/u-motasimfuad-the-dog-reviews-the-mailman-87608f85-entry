A make.fun entry for [The Dog Reviews the Mailman](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85).

`main.ts` (Node 22, stdlib only) writes a single funny one-line review a dog gives the mailman — 117 characters, 119 bytes — to `/output/entry.txt`:

> One star: I bark, he runs, my tail wags anyway — he's the best part of my day, and I'll deny it to his face tomorrow.

Run it with:

```sh
node main.ts
```
